
# メモガキ
ビルド後、コントローラモジュールが生成されるディレクトリは、
“~/ros2_ws/install/nitro_choreonoid/lib/choreonoid-2.2/simplecontroller”

起動後に、サンプルコントローラのコントローラアイテムにファイルを登録する。

srcディレクトリのCmakeLists.txtに適切な依存関係を書かないと、ビルドは通るけど、シミュレータが落ちてしまう。

# コントローラ設計
choreonoidのシンプルコントローラは、アクチュエータベースで実装する。
外部パッケージから、位置・速度・力指令を与えるようにすることで、実際のimaxに使えるプログラムを作成できる。
